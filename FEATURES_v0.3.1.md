- Odev olustururken fotograf cekme

- PDF ekleme

- Ogretmenin teslim dosyalarini uygulama icinden gormesi

- Velinin tum odev dosyalarini goruntulemesi
- Odev listesinde materyal/teslim dosyasi sayaci
- Private Supabase Storage
- 15 dakikalik signed URL ile guvenli dosya goruntuleme
- 10 MB dosya limiti
- RLS ile ogretmen / ogrenci / veli erisim kontrolu
